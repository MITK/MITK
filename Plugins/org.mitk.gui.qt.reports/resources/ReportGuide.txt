For the user to read, save as HTML or print; the user decides what to keep. Body: {title, html}, html being the body of an HTML page. Opens without taking the keyboard focus. Returns {data: {id, title, images, modified}} with status 201.

The page brings its own style sheet, light or dark as the Workbench is, and shows the title and date, so start with the content. The Workbench shows it with litehtml, a browser once it is saved; both look the same as long as the page uses the components below and, for anything else, the CSS that litehtml renders. Build the page from them: a banner with the main finding, the key numbers, warnings as callouts, numbered sections, a card per structure.

Components:
- Banner: <div class="hero"><div class="hero-text"><div class="kicker">Topic · CT</div><h2>The finding,<br><span class="hl">in a few words.</span></h2><p>One or two sentences.</p><div class="chips"><span class="chip">512 × 512 × 139 voxels</span><span class="chip">Not corrected by hand</span></div></div><div class="hero-media"><img src="image-1.png" width="400"></div></div>
- Key numbers, two to four: <div class="kpis"><div class="kpi" style="--c: #be0032"><div class="value">2664<small>ml</small></div><div class="label">Segmented liver</div></div></div>
- Message: <div class="callout warn"><div class="icon">!</div><div class="body"><p>Text</p></div></div>; warn, ok (icon ✓), or info without a second class.
- Section: <h2><span class="num">01</span>Title</h2>; h3 and h4 below it.
- Columns of equal width, any number: <div class="columns">…</div>; class "columns tight" spaces them 6 px apart. Panels, boxes, tiles and shots go in them.
- Panel: <div class="panel"><div class="panel-title">Caption</div>…</div>; class "panel center" centers images and text.
- Box, a small card: <div class="box"><div class="num">01</div><h4>Step</h4><p>Text</p></div>; class "box marked" with style="--c: #rrggbb" adds a colored top edge.
- Tile, a colored block, for example a segment in a schematic map: <div class="tile" style="--c: #rrggbb; --on-c: #1d2600"><div class="value">7</div><div class="label">581 ml</div></div>
- Card, one per structure: <div class="card" style="--c: #be0032; --on-c: #ffffff; --c-soft: rgba(190, 0, 50, 0.22)"><div class="card-header"><div class="badge">1</div><div class="card-title"><h3>Name</h3><div class="sub">Where it is</div><div class="flags"><span class="flag warn">Truncated</span></div></div><div class="card-value"><div class="value">168.2<small>ml</small></div><div class="muted">6.3 % of the liver</div><div class="meter"><i style="width: 29%"></i></div></div></div><div class="card-body"><div class="columns"><div class="shot"><img src="image-5.png"><span>Axial · 24</span></div><div class="shot"><img src="image-6.png"><span>Coronal · 229</span></div></div></div><div class="card-footer"><div class="stats"><div class="stat"><b>32.2</b><span>Mean</span></div><div class="stat"><b>27.9</b><span>SD</span></div></div><p>What to look at.</p></div></div>. Flags are warn, info, ok or plain.
- Also: table with th and td (class "number" aligns right), span class="swatch" style="background: #rrggbb" before a label name, figure with img and figcaption, p class="muted", div class="footer" for a last line.

Colors: --c is a label's color, --on-c a text color that reads on it, --c-soft the label's color as rgba() at 0.22 for the tint of a card's header. Leave the colors of the page, text, panels and lines to the style sheet, which sets them for the theme; in your own CSS, use var(--text), var(--muted), var(--heading), var(--panel), var(--line) and var(--accent) instead of fixed colors.

Your own CSS, in a <style> element or style attributes, only for what the components lack. litehtml renders: block and inline-block; flex (direction, wrap, align-items, justify-content, flex: 1 1 0) without gap, so space items with margins; tables; position relative and absolute; margins, padding, borders and border-radius; linear and radial gradients; var(). Not rendered, so browsers would show something else: grid, gap, calc(), transform, opacity, box-shadow, text-shadow, filter, letter-spacing, object-fit, color-mix(), background-clip: text, a length for vertical-align, the same variable twice in one declaration, one corner's radius above half the box's width or height; dashed, dotted and double borders are drawn solid. Use font weights 400, 600 or 700, fixed widths rather than min-width in rows, and center absolutely positioned boxes with negative margins. litehtml applies a declaration with var() after one without, whatever the selectors: override a var() declaration with another var() declaration.

Charts: inline <svg>, sized in pixels with its width and height attributes and with a viewBox of that size, so that a chart wider than its place shrinks in proportion, styled by its own attributes. In the Workbench neither the style sheet nor the theme reaches into it, while a browser lets the page's font and rules in: set font-family and font-size on the <svg> element, use no <style> element and no nested <svg> in it (a g with a transform instead), and place text with x, y and text-anchor, as dominant-baseline is not rendered. Use the labels' colors for data, #8a93a3 for text and axes, stroke-opacity for grid lines, and font weights up to 700.

Images: screenshots come from POST /api/v1/reports/images and are referred to by name, only as <img src="image-3.png"> with the value in quotes (a report with an unquoted src is refused), never in CSS (url(...)); a width attribute in pixels sets the size shown. Your own figures may be embedded as data: URIs. A report takes at most 32 MB of HTML. Known limit: text that contains src="..." is taken for an image reference. No scripts.
